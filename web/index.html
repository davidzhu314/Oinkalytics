How we tested

Most demos test on a random shuffle of calls, so the model has already heard the same room and microphone. We test on recordings it has never heard, and report that number.

90%random split (the usual way)
67%recordings it never heard
76%when it's allowed to say "not sure"
86%pigs it never heard, within one study

Balanced accuracy, where guessing scores 50%. Data: SoundWel (Briefer et al. 2022, CC BY 4.0). Model: Perch 2.0 embeddings + calibrated logistic regression. Not yet tested in a noisy real barn.

Then we tried chickens, and caught the model cheating

Same pipeline, a second species: healthy vs sick chickens. It scored 99.6% on recordings it had never heard. We didn't believe it, so we checked what else could explain it.

99.6%chicken recordings it never heard
0.1points lost on unseen recordings (pigs lose 23)
93.9%from 7 simple loudness and noise numbers, no AI
81.5%from loudness alone

So what is it hearing? Either each folder was recorded with a different microphone or room, or sick birds really do sound different (rattly, laboured breathing shifts the sound in exactly this way). The dataset has no recording details, so nothing can tell those apart. We report it as a confound, not as a 99.6% disease detector: the pipeline moved to a new species in a few hours, and the first thing it did was expose a shortcut a quick read would have published.

Data: Mendeley "Poultry Vocalization Signal Dataset for Early Disease Detection" (346 recordings, CC BY 4.0). Simple features and model scored on the same split, holding out whole recordings.

Does each model know its own animal?

The mixed pens send every call to both models, and a call only counts for the model that recognises its own animal.

Our weak spot: half-second chicken squawks sound pig-like to the audio model. Retraining the pig model's "not a pig" check with 250 chicken recordings barely helped (93% to 94% rejected), so we kept the original model and say so here.

How it's built, and what the AI does and doesn't do

  1. Pretrained, not changed1. Listen

    Perch 2.0, Google's model for bird and animal sounds, turns each call into 1,536 numbers.

  2. Trained by us2. Decide

    A small classifier learns calm vs distressed from 6,661 labelled pig calls, or healthy vs sick from 248 chicken recordings.

  3. Fitted by us3. Calibrate

    So that "80% sure" is right about 80% of the time. When it's too close to call, it says "not sure".

  4. Trained by us4. Check the animal

    A not-a-pig / not-a-chicken check, plus a "too unlike anything it trained on" check, rejects claps, coughs and the other species.

  5. AI writer, not trained5. Explain

    A language model turns the measured numbers into one plain sentence. It never hears the audio, and anything it adds that isn't in the evidence (a new number, a feeling like "scared", a disease name) is rejected and a template is used instead.

No language model was trained. Every test holds out whole recordings: the classifier, calibration, similar-call search and animal checks never see the demo clips.
